# Python Intrusion Detection System (IDS)

## Project Description

This project implements a basic Intrusion Detection System (IDS) using Python and the Scapy library. 
The system analyzes network traffic to detect suspicious activities such as port scanning and abnormal SYN packet behavior.

The IDS supports two main modes:

• Offline analysis using PCAP files  
• Live monitoring of network traffic

This project demonstrates fundamental cybersecurity concepts such as packet inspection, network monitoring, and attack detection.

## Features

• Offline PCAP packet analysis  
• Live network traffic monitoring  
• Port scan detection  
• SYN packet activity detection  
• Top source IP traffic identification  
• Traffic categorization using NumPy  
• Alert logging system  
• Modular Python IDS design

## Installation

Install the required Python libraries:

pip install scapy numpy

## Running the IDS

## Offline mode 
py scripts/ids_basic.py offline captures/sample_traffic.pcap

## Live mode 
py scripts/ids_basic.py live

## Alert Logging

All alerts are saved to:

logs/alerts.log

## Testing

Attacks can be simulated using Kali Linux and Nmap.

Example port scan:

sudo nmap -sS -p 1-1000 <target-ip>

The IDS should detect this activity and generate alerts.

## Improvements

The IDS was improved by:

- Expanding alert log details to include the actual destination ports involved in a detected port scan
- Adding try/except error handling for file reading and log writing
- Replacing repeated numeric values in loops with named constants for cleaner, more maintainable code
